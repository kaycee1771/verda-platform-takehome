# Phase 0 Evidence

Commit only sanitized summaries. Raw account discovery and provider schemas use the `.local.json` convention and are ignored.

Expected final evidence:

- Toolchain versions.
- Redacted CPU SKU, image, location, volume, and availability summary.
- Provider version and a reviewed resource/data-source capability summary.
- Cost scenario inputs with collection timestamps.
- Phase 0 validation output.

Do not commit project IDs, live instance IDs, public IPs before the access review, credential paths, tokens, secrets, or raw debug logs.
